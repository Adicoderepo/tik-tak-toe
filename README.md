# Tic Tac Toe Game

Python और Tkinter से बनी एक शानदार Tic Tac Toe गेम!

## 🎮 विशेषताएं

- **सरल और उपयोग करने में आसान GUI** - Tkinter के साथ बनी सुंदर इंटरफेस
- **दो खिलाड़ियों के लिए खेल** - अपने दोस्त के साथ खेलें
- **जीत का पता लगाना** - गेम स्वचालित रूप से विजेता को पहचानता है
- **खेल को रीसेट करें** - नया खेल शुरू करने का विकल्प

## 📋 आवश्यकताएं

- Python 3.6 या उससे अधिक
- Tkinter (आमतौर पर Python के साथ पहले से आता है)

## 🚀 शुरू करने के लिए

### 1. Repository को Clone करें

```bash
git clone https://github.com/Adicoderepo/tik-tak-toe.git
cd tik-tak-toe
```

### 2. गेम को चलाएं

```bash
python main.py
```

या अगर आपके पास Python 3 है:

```bash
python3 main.py
```

## 🎯 कैसे खेलें

1. गेम खुलने के बाद एक 3x3 ग्रिड दिखाई देगी
2. खिलाड़ी 1 **X** है और पहले चलता है
3. खिलाड़ी 2 **O** है
4. बारी-बारी से किसी खाली जगह पर क्लिक करें
5. तीन समान चिन्हों को एक पंक्ति में (क्षैतिज, लंबवत या तिरछे) प्राप्त करें
6. जीतने वाले को एक संदेश दिखाया जाएगा
7. **Reset** बटन दबाकर नया खेल शुरू करें

## 📦 इंस्टॉलेशन की समस्याएं

### Tkinter नहीं मिल रहा?

**Windows पर:**
- Python को फिर से इंस्टॉल करते समय "tcl/tk and IDLE" को चेक करें

**Linux पर:**
```bash
# Ubuntu/Debian
sudo apt-get install python3-tk

# Fedora
sudo dnf install python3-tkinter
```

**macOS पर:**
```bash
brew install python3
```
